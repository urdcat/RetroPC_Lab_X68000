# 開発環境と実機検証

更新: 2026-07-12

## いま採用する構成

| 層 | 採用 | 理由 |
| --- | --- | --- |
| ホスト | Windows + MSYS2 MinGW 64-bit | xdev68k が公式に案内する構成。普段のWindows作業と共存できる。 |
| X68000 ビルド | xdev68k の run68 + HAS060 + HLK | Motorola記法のアセンブルとリンクで、Human68k の X形式実行ファイルを作る。 |
| 実行確認 | 同梱のXEiJ → X68000 Z | PC で高速に反復し、節目で実機との差を確認する。 |
| 実機転送 | 所持済みの手段 | `MAIN.X` を Human68k から読める書込み可能な媒体へコピーする。転送方法は無理に置換しない。 |
| 将来のMD | 68000アセンブラ + MD専用ROMビルド | CPU中核の記述を保ちつつ、ROMヘッダ・VDP・音源だけを置換する。 |

MSYS2 は `C:\\msys64`、xdev68k は MSYS2 のホーム `~/xdev68k`
（Windows では通常 `C:\\msys64\\home\\<ユーザー名>\\xdev68k`）に置く。ここにはクロス
ホスト側の `run68` とX68000側の `HAS060.X` / `HLK301.X` はこの外部ツール領域に置くため、
OneDrive 同期中のリポジトリを重くしない。

## PCエミュレータ

公式配布のXEiJ 0.26.07.08を`tools/third_party/xeij/XEiJ-0.26.07.08/`にローカル導入する。
展開後は約790MBになるためGit管理しない。未導入の環境では次で公式配布物を取得する。

```powershell
.\tools\Get-XEiJ.ps1
```

XEiJの起動には**OpenJDK 26以上**が必要で、Java本体はリポジトリに含めない。

```powershell
.\tools\Run-XEiJ.ps1
```

このスクリプトはX68000 EXPERT相当、MC68000、10MHz、2MBメモリ、公式配布物のHuman68k 3.02を指定して
起動する。エミュレータのライセンス、ソース同梱条件、ホストファイルシステムを使う際の注意は
[EMULATOR_XEIJ.md](EMULATOR_XEIJ.md)を参照する。

## アセンブラ環境の構築

MSYS2 MinGW 64-bit シェルで実行する。

```bash
cd ~/xdev68k
bash ./install_xdev68k-utils.sh
```

完了後は `~/.bashrc` に次を追加する。

```bash
export XDEV68K_DIR="$HOME/xdev68k"
export LC_ALL=C
export LC_CTYPE=C
export LANG=en_US.UTF-8
```

### 最初の成功条件

```bash
cd /d/work/X68000で何か作ろう/src/platform/x68k
make
```

ここで `build/HELLO.X` が生成される。これは X68000 側で起動する実行ファイルであり、Windows 実行ファイルではない。
まずエミュレータで `hello world.` を確認し、次に既存の転送手段で X68000 Z の Human68k 環境へ
コピーして実行する。

## X68000 Z への転送時の注意

- X68000 Z の **ゲーム専用SDカードは開発用に使わない**。Human68k を起動できる書込み可能な
  システム媒体または、使用中のHDS/転送手段を使う。
- 公式資料では、市販SDカードを使う場合は SDHC・32GB以下・FAT32 と案内されている。実機の
  ファームウェアと手元の起動媒体で先に確認する。
- XDF は 1,261,568 bytes のRAWフロッピーイメージである。空のXDFはHuman68k側で format してから使う。
- Pseudo SCSI を使う場合、HDS はUSBメモリ上のファイルとして扱われる。開発データは小さな作業用
  HDS に置き、OSや配布物の原本は別に保管する。
- 実機確認は、最初は `HELLO.X` の起動、表示、終了の三点だけに絞る。描画・音源・入力・タイミングは
  エミュレータとの差があり得るため、その後に段階的に検証する。

## メガドライブへ流用する境界

共有してよいもの:

- ゲームルール、状態遷移、乱数、固定小数点の算術
- 68000命令だけで書いた小さなアセンブラルーチン
- タイルやスプライトの原画、効果音・曲の原データ、素材一覧
- テスト用の入力記録と期待状態

共有しないもの:

- `.X` と ROM、リンカ設定、スタートアップコード
- Human68k DOS/IOCS 呼出しと、メガドライブのVDP/音源制御
- X68000 のビットマップ/スプライト描画と、MDのタイル/VDP/DMA描画
- X68000 音源と、MD の YM2612/Z80 音源制御

この境界を守るため、共通コードは `src/core/` だけに置き、各機種のIOCS・VDP・音源レジスタを
`src/core/` から直接触らない。
