# M68K/X68000 アセンブラ基盤

更新: 2026-07-13

## 判断

商用作品の基盤は、HAS060.X のみには置かない。HAS060.X と HLK301.X は当面、既存の `.X` を
比較するための互換性オラクルとして残す。

`vasm` は、Motorola記法、マクロ、構造体、条件アセンブル、MC68000指定、X68000 Xfile出力を
備える有力な既存実装である。しかし公式ライセンスは、AmigaOS以外の商用利用に作者の書面同意を
求めている。X68000向けの商用作品では、許諾を得るまで採用しない。

このため、このリポジトリではホスト用の独自ツール **m68kasm** を育てる。名称は実装中の仮称であり、
最終製品名ではない。

## 目標

- Windows上で動く、MC68000専用のクロスアセンブラとリンカ。
- 代数記法、`[手続き]` / `]/`、構造体、手続きローカル変数、1行複数命令を入力言語として持つ。
  詳細は [ASSEMBLER_LANGUAGE.md](ASSEMBLER_LANGUAGE.md) に固定する。
- X68000ではHuman68k Xfile (`.X`) を、メガドライブではROMイメージを出力するターゲットプロファイル。
- プロジェクト独自のレジスタ契約を、ソース上の宣言として検査する。
- ツール自身は外部の非商用ライセンスに依存しない。コードと仕様はクリーンルームで管理する。

## 実装段階

1. **言語フロントエンド** — 代数記法、手続き、ローカル変数、構造体、1行複数文を構文解析し、短い診断を出す。
2. **縦切り** — 単一モジュール、MC68000の最小命令、ラベル、定数、Xfile直接出力。
3. **アセンブラ本体** — 全68000命令・全実効アドレス・式・ローカルラベル・include・マクロ・条件アセンブル。
4. **モジュール化** — 独自の再配置可能オブジェクト、`xdef`/`xref` 相当、ライブラリ、リンカ、マップ。
5. **製品向け機能** — レジスタ契約検査、命令サイクル見積り、VRAM/DMA境界の静的検査、XEiJ用ソースマップ。
6. **メガドライブプロファイル** — ROMヘッダ、固定配置、VDP/Z80向けの制約を追加する。ただしCPUコアは共有する。

現在の `tools/m68kasm/` は第1段階である。対応外の構文を黙って通さず、明示的にエラーにする。

## Xfileの初期制約

初期Xfile出力は、Xfileの単純な範囲に限定する。

- code/data/bss は各1セクションまで。
- 外部未解決シンボルは許さない。
- 再配置は第2段階まで保留し、入口ラベルはコード先頭に置く。

これは既存実装のXfile出力が示す制約とも整合する。複数モジュール・再配置・複雑なセクションは、
独自リンカを実装してから有効にする。
