# m68kasm 0.9.0-preview.1

MC68000～MC68030用のターゲット非依存クロスアセンブラ、その内部利用向けプレビュー版です。
このパッケージは単体で動作し、.NET、HAS060、run68、XEiJなどの別途インストールを必要としません。

## 使い方

```powershell
bin\m68kasm.exe --version
bin\m68kasm.exe selftest
bin\m68kasm.exe check examples\language_features.m68 --cpu 68000
bin\m68kasm.exe assemble examples\language_features.m68 -o build\language_features.bin --cpu 68000
bin\m68kasm.exe assemble examples\labels_and_addressing.m68 -o build\addressing.bin --base-address 0x200
bin\m68kasm.exe assemble x68030.m68 -o build\x68030.bin --cpu 68030
```

`assemble`は、ヘッダーを含まない68kビッグエンディアン機械語を出力します。
`check`は出力ファイルを作らず、構文解析と指定CPUでの2パス機械語生成を検査します。
`assemble`と同じ`--cpu`および`--base-address`を指定できます。
ROMベクターテーブル、ROMヘッダー、メモリ配置、チェックサムなどは、このツールを利用する側の
ターゲットプロジェクトが担当します。そのため、このパッケージ自体はX68000にもメガドライブにも
依存していません。

別プロジェクトでは、展開したディレクトリをそのまま`tools/m68kasm/`などへ置いてください。
少なくとも`bin/m68kasm.exe`と`licenses/`は一緒に保持してください。

## 現在の対応範囲

- `--cpu 68000|68010|68020|68030`。省略時は`68000`
- MC68000の全命令ファミリ
- MC68010のBKPT、MOVE CCRから、MOVEC、MOVES、RTD
- MC68020のビットフィールド、CAS、ロング乗除算、ロング分岐、拡張実効アドレスなど
- MC68030内蔵MMUのPFLUSH、PLOAD、PMOVE、PTEST

- `d0.b`～`d7.l`の明示的なデータレジスタ幅
- 10進、16進、2進の即値
- `=`、`+=`、`-=`と、代入右辺の単一`+`または`-`
- 手続きと、`local`によるbyte、word、long、ptr型ローカル変数
- ローカル利用時の`LINK A6`、`UNLK A6`
- `]`による自動`RTS`と、`]/`によるRTS抑止
- 引数なし／引数付き`defmacro`と、複文引数
- 複文の字句ラベルスコープと、マクロ呼び出しごとの独立ラベル
- 相対`include`と循環include検出
- `ifasm (定数式) { ... } else { ... }`
- `NAME equ 式`形式の定数ラベルと、前方参照・循環参照検出
- 括弧と優先順位を持つ数値式
- `base`レジスタ付き構造体と`構造体,フィールド`形式の代数ロード／ストア
- 手続き名、グローバルラベル、`.loop`形式の手続きローカルラベル
- `.s`、`.w`、68020以降の`.l`条件分岐
- レジスタ直接、アドレス間接、ポストインクリメント、プリデクリメント、16ビット変位、
  インデックス、絶対ワード／ロング、PC相対、即値、および68020拡張実効アドレス
- `dc.b`、`dc.w`、`dc.l`、`defb`、`defw`、`defl`、`defs`
- `align 境界[,詰め値]`と`even`
- `--base-address`による絶対シンボルアドレス指定

外部シンボル、再配置可能オブジェクト、オブジェクトリンク、コマンドラインからの定数定義は未実装です。
68881/68882浮動小数点命令は別コプロセッサプロファイルとして将来対応します。
未対応文はエラーとなり、部分的なバイナリを成功出力しません。

## 終了コード

- `0`: 成功
- `1`: 入力構文または機械語生成エラー
- `2`: コマンドライン、入力ファイル、出力ファイルのエラー

## ライセンス上の位置づけ

このリポジトリには、m68kasm本体を第三者へ公開再配布するためのライセンスがまだ設定されていません。
この成果物は、同じ開発主体が管理する別プロジェクトへ移すための内部プレビュー版です。
公開配布する前に、m68kasm本体のライセンスと権利者表記を決定してください。

同梱された.NETランタイムのライセンスと第三者通知は`licenses/dotnet/`にあります。
